# Site HTML Simples

Um site moderno, responsivo e acessível feito com HTML, CSS e JavaScript.

## Como usar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html` no seu navegador.

Não é necessário servidor. Se preferir, você pode usar uma extensão de "Live Server" no seu editor.

## Estrutura

- `index.html` — Página principal com seções Início, Serviços, Sobre e Contato.
- `styles.css` — Estilos com layout responsivo e design moderno.
- `script.js` — Menu móvel e rolagem suave; feedback no formulário.

## Personalização rápida

- Título do site: edite a tag `<title>` no `index.html`.
- Cores: ajuste as variáveis em `:root` no `styles.css`.
- Itens do menu/Seções: edite o HTML conforme necessário.
